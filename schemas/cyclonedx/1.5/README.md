# CycloneDX 1.5 validation schemas

These are unmodified upstream files from
[CycloneDX/specification at c320fc0f0b46873864927d9d5684eea7ba439728](https://github.com/CycloneDX/specification/tree/c320fc0f0b46873864927d9d5684eea7ba439728/schema)
(the `1.5` tag), licensed under the included Apache 2.0 license. The JSF schema
retains its upstream attribution. `SHA256SUMS` records the downloaded bytes.

`scripts/validate_sbom.py` verifies these hashes, registers all referenced
schemas locally, and validates without network retrieval. Update the pinned
revision and download the complete schema set together; do not edit schema
contents to accommodate invalid output. Fix the SBOM generator instead.
